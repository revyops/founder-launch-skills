# Words you will hear

| Word | What it means |
|---|---|
| Agent | An AI that does work on its own (reads, searches, writes files, uses tools) rather than only answering in chat. Claude can start several at once for a big job |
| Claude Code | The mode of the Claude app that works on your computer: it reads and writes files, uses tools and runs jobs |
| Cowork | The mode of the Claude app built for office work |
| Chat or session | One conversation with Claude. Keep one per piece of work |
| Markdown file | A plain text note with simple formatting (`#` for a heading, `-` for a bullet). Easy for people and AI to read. Every note in your vault is one |
| Vault | A folder of markdown notes that a notes app displays |
| Knowledge graph | Your notes, linked to each other, so the AI can follow a thread across them |
| Skill | A note of instructions for a kind of work, which Claude loads when that work comes up |
| Memory | Short facts Claude keeps about you between conversations |
| `CLAUDE.md` | A note in your working folder with standing rules Claude reads at the start of every session |
| Connector or MCP | A link that lets Claude use one of your tools directly. MCP is the technical name for the standard most connectors use |
| CLI | A command-line tool. Does the same job as a connector for some tools |
| API key | A long password a tool generates so another program can use it. Paste it only into the tool's own setup screen, never into a chat |
| Sign-in window (OAuth) | The pop-up where you approve Claude's access to a tool |
| Token | The unit AI work is measured and paid in. Roughly a short word |
| Context window | How much Claude can hold in mind at once |
| Compacting | Claude summarising the older part of a long chat to make room. Details can get lost |
| Hallucination | Claude stating something untrue with confidence |
| Permission mode | How much Claude asks before acting. Bypass permissions means it does not ask |
| Scheduled job | Work Claude runs on a timetable. Local jobs need your computer awake; cloud jobs do not |
| Remote control | Checking on and answering Claude from your phone |
