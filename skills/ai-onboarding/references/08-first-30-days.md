# Your first 30 days

Copy this note into your vault as `AI Setup Progress.md` and tick items off as you go. Claude can keep it up to date.

## Day 1: set up (2 to 3 hours)

- [ ] Claude desktop app installed, paid plan active
- [ ] Notes app installed, vault created in Documents
- [ ] Voice dictation installed, shortcut tested
- [ ] New Code session started with the vault folder selected
- [ ] Settings checked: keep computer awake, remote control, permissions
- [ ] Standing rule saved: never send, spend, publish or delete without showing me first
- [ ] Standing rule saved: no new top-level folders without asking
- [ ] Vault folders laid out, each with a `00 - Start Here` note
- [ ] Meeting recorder connected
- [ ] Slack or Teams connected
- [ ] Aim and constraint written into the vault

## Week 1: first use case

- [ ] Recurring tasks listed and scored; first use case chosen
- [ ] The tools that use case needs are connected
- [ ] Claude has read the history and written a summary of where things stand
- [ ] Outside baseline researched, with sources, and saved
- [ ] First version of the output built (a report, a set of drafts, a review)
- [ ] At least three rounds of "not like that, like this"
- [ ] Fewer permission prompts once comfortable
- [ ] End-of-session save done after every working session

## Weeks 2 and 3: make it run without you

- [ ] First skill written from the work you liked
- [ ] Copy rules built from your own writing
- [ ] First scheduled job running, with a draft-then-approve step for anything that leaves your desk
- [ ] Spot-checked the job's numbers against the source tool at least twice
- [ ] Running to-do list of what Claude is waiting on you for
- [ ] Shared vault set up with your team, if you have one
- [ ] Second use case started

## Week 4: review

- [ ] Review job running each morning across all jobs
- [ ] Vault reviewed for duplicates, contradictions and stale notes
- [ ] Asked Claude: "What have you been unsure about, and what did you assume rather than check?"
- [ ] Written down: hours saved per week, what works, what still needs you
- [ ] Next 30 days' use case chosen

## You are on track if, by day 30

- At least one job runs on a schedule and you trust its output after a quick look.
- Claude has stopped repeating the mistakes you corrected in week one.
- You have more than one chat running most days.
- A new chat can pick up your work by reading the vault, without you explaining it again.
